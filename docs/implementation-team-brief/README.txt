1. Scope and implementation order
2. Data contract, model mapping, and hashing
3. One circuit with step-by-step pseudocode and six checks
4. External audit, acceptance tests, and source-code map

This is a separate implementation handoff, not a replacement for the paper.
The current source was checked against the local repository on 1 October 2026.
Commands and tests in the brief are acceptance criteria for the team; this
documentation task does not assert a fresh execution of the full test suite.
